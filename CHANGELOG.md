# Changelog

## 0.3.1-dev — 2026-10-29

- Исправлен вылет при разрушении скалы в Бастионе знаком «Удар», в том числе
  на восьмом цикле. При пустом кэше шейдеров отложенная сборка возвращала
  частично заполненные проходы отрисовки, а движок уже использовал их данные
  освещения. Теперь сборка проходов завершается перед использованием результата.
- Исправление действует в The Void 2009 и Tension 2008. Проверены оригинальные
  вызовы построителя в обеих версиях; тест проверяет пустой и готовый кэш,
  завершённость проходов и стек, а также обнаруживает возврат прежней ошибки.
- На Pixel 10a проверены разрушение скалы с пустым кэшем и повтор после
  перезапуска в отдельном тестовом профиле 2009: обломки отлетают, жила открывается,
  игра продолжает работать. Исходные сохранения сохранены. Живой тест Tension
  2008 не проводился. Просадки FPS от обломков остаются; при первом появлении
  нового эффекта возможна пауза компиляции.
- Версия APK — `0.3.1-dev`, код — `5`; сохранён прежний ключ подписи для
  совместимого обновления.
- Сборщик автоматически включает основной текст GPL и уведомления о сторонних
  компонентах, уже входившие в опубликованный APK 0.3-dev.

## 0.3-dev — 2026-10-28

- Версия APK — `0.3-dev`, код — `4`; сохранён прежний ключ для совместимого
  обновления. Из исходников и документации убраны личные пути, адреса локальной
  сети и серийные номера устройств; инструменты получают устройство явно.
- `STATE.md` и `research/` исключены из отслеживания Git и добавлены в
  `.gitignore`; локальные рабочие материалы сохранены. README полностью
  переведён на английский, ранние этапы Windows явно отмечены как исторические.
  Релизный коммит подписывается GPG-ключом пользователя с публичным GitHub-автором.
- Исходники ASTC Encoder и etcpak заменены Git submodules с закреплёнными
  ревизиями: ASTC Encoder 5.7.0 (`baff485b`), etcpak (`3d716e15`, вместе с
  bcdec). Обновлены пути Android- и Windows-сборки конвертера и проверки
  зависимостей; недостающие submodules инициализируются автоматически.
- Новый вариант шейдера больше не останавливает игру на секунды. Варианты,
  которых нет ни в кэше игры, ни в комплекте порта (их выбирают свет, тени и
  туман вокруг объекта, поэтому, например, подбор ростков разного цвета и
  размера давал очень длинные кадры), теперь компилирует отдельный процесс на
  малых ядрах процессора. Игра продолжает рисовать, а объект появляется, как
  только вариант готов; в кадре, где уже ждут вариант, на построение эффектов
  уходит не больше 8 мс. Скомпилированные варианты сохраняются в личной папке
  приложения, а не через общую память телефона: одно это вдвое сократило и
  компиляцию прямо в кадре. На POCO X3 NFC с холодным кэшем шейдеров (Зев,
  Светлячки, Озеро Ире) компиляций прямо в кадре стало 34 вместо 296, а самый
  долгий кадр после входа на локацию — до 0,9 с вместо 4,6–21 с.
- Сервис шейдеров загружает только рекомпилированный компилятор, использует
  отдельный нативный поток с достаточным стеком и завершается вместе с игрой.
  Повторные запросы ещё не готового эффекта не строятся заново каждый кадр;
  ошибки этого ожидаемого состояния не засоряют игровой журнал. При
  недоступном или зависшем сервисе игра возвращается к компиляции в своём потоке.
- Вылеты 0.2-dev под Мостом и в конце коридора Колыбели Оле были из-за
  шейдера тени. Если нужного варианта не было в комплекте, игра без
  компиляции на устройстве падала. Теперь такой вариант компилируется на
  устройстве за десятки миллисекунд, а 19 вариантов из Колыбели Оле добавлены
  в комплект.
- Экран тела («Камера Духа») больше не перестаёт отвечать, когда открыта
  зона 0 (например, после `/giveall`) и из Памяти берут Цвет. Подписи с
  количеством при переносе Цвета из Памяти теперь стоят над своими сердцами,
  а не над соседними.
- При выключенных текстурах высокого качества картинки локаций на карте
  показываются в полный размер. Игра загружала их на уровень меньше и
  рисовала в четверть места (так было и в оригинале). Текстуры сцен
  по-прежнему уменьшаются.
- Меню заранее собирает 520 программ OpenGL ES, записанных в реальной игре на
  POCO X3 NFC и Pixel 10; в комплект шейдеров добавлены 105 вариантов с этих
  телефонов и пакет из 4402 вариантов, заранее сгенерированных штатным
  прегенератором игры.
- Монстр-прыгун в Зеве больше не пропадает (на экране оставалась только его
  тень), а сбор цвета из ростка в Светлячках и подобные сцены больше не
  проседают. Причина — варианты шейдеров, которых нет в комплекте: игра
  пыталась сгенерировать такой вариант в каждом кадре и не рисовала объект.
  Теперь недостающий вариант один раз компилируется на самом устройстве
  (60–300 мс на Snapdragon 732G) и сохраняется в профиле. В комплект
  добавлены 28 вариантов, найденных на этих сценах.
- Шаг физики подстраивается под частоту кадров: 1/60 с, пока игра показывает
  меньше 58 кадров в секунду, и частота экрана, когда больше 72. На экранах
  120 Гц физика больше не считается по 3–4 раза за кадр.
- Лаунчер показывает, читает ли видеочип DXT-текстуры игры. Если не читает,
  он предлагает один раз сконвертировать их в ASTC 4×4 или ETC2: 8825
  текстур, включая 5906 кадров анимированной воды, около 3,5 ГБ для ASTC и
  3,0 ГБ для ETC2. Видеочипы с S3TC получают DXT-блоки без распаковки. На
  POCO X3 NFC даже копия без анимаций подняла FPS на Памяти с 25,6 до 38,2,
  на Остове — с 23,5 до 32,2, а графическую память процесса сократила с 850
  до 478 МБ.
- Конвертация текстур выполняется в нескольких потоках, сохраняет mip-уровни,
  альфа-канал и грани кубических текстур, объединяет дубликаты. Лаунчер показывает
  объём, прогресс, отмену и удаление копии; фоновый сервис поддерживает работу
  с уведомлением. Проверяется свободное место; результат сначала пишется во
  временный файл, существующая копия заменяется только после успешного завершения.
  Интерфейс новых настроек доступен на английском, русском, немецком и польском.
- Рендерер читает индекс сконвертированных текстур и загружает сжатые блоки
  прямо в GPU. Для неподдерживаемого формата остаётся обычная загрузка; запись
  игры в текстуру переводит её обратно в изменяемое представление.
- Устаревшая папка `lifted` без нового образа `d3dx9_36.dll` больше не
  перекрывает образы из APK.
- В лаунчере появилась настройка «Ограничение FPS». Варианты берутся из
  частот обновления этого дисплея: игра просит у системы такой режим экрана,
  а если он не включился, сама держит предел.
- Анизотропная фильтрация по умолчанию теперь ×4 вместо ×16. Прежнее
  значение по умолчанию переводится на ×4 один раз.
- В настройках графики появился переключатель «Отражения в воде». Своего
  такого переключателя в игре нет: водяное зеркало рисует сцену второй раз в
  каждом кадре. Выключенное, оно поступает так же, как сама игра, когда камера
  за зеркалом: отражение становится чёрным, а сцена второй раз не рисуется.
  По умолчанию отражения включены. Выключенные на Озере Ире дают 26,5 FPS
  вместо 18,6 (вода тогда выглядит тёмной и матовой).
- Освещение неподвижных объектов больше не пересчитывается каждый кадр:
  повторяется сохранённый результат обхода дерева регионов. На Озере Ире этот
  обход занимал пятую часть кадра.
- Ускорен поиск часто вызываемых COM-объектов; освобождённые объекты и повторно
  занятые слоты по-прежнему проходят проверку. Статистика кадров дополнена
  максимальной длительностью кадра и числом кадров дольше 50 мс.
- В Tension 2008 перенесены изменения этой версии: компиляция недостающих
  шейдеров на устройстве (теперь по умолчанию, как в 2009) и в отдельном
  процессе, конвертация текстур в ETC2/ASTC в лаунчере, DXT без распаковки на
  видеочипах с S3TC, шаг физики по частоте кадров, ограничение FPS, разовый
  перевод фильтрации с ×16 на ×4, переключатель «Отражения в воде» (в панели
  настроек порта: своих страниц порта в меню Tension нет), кэш
  регионального освещения, быстрый поиск COM-объектов, проверка папки
  образов, подписи сердец на экране тела, полный размер картинок локаций на
  карте и нативные части звука, навигации, распаковки и физики. Нативный код
  2009 подключается к функциям Tension, только если они совпадают байт в
  байт с точностью до адресов. На устройстве эти изменения в Tension пока не
  проверялись.
- Генератор выпусков находит соответствующие нативным подменам функции Tension
  по машинному коду с учётом релокаций и внешних переходов, проверяет размеры
  и адреса констант. Общие модули, включая компилятор D3DX, подключаются к
  сборке и диспетчеризации выпуска; адреса шагов PhysX 2.7.3 извлекаются отдельно.
- APK включает пакет предгенерированных шейдеров с индексом и SHA-256,
  библиотеку конвертера и лицензии кодеков. Добавлены и обновлены проверки
  целостности пакета, Java, выбора образов, шага физики, конвертации текстур,
  нативных подмен Tension, интерфейса и сохранения исходного ключа подписи.
- Не перенесены в Tension: заранее сгенерированный пакет шейдеров и рецепты
  прогрева (их нужно собрать на локациях Tension; совпадающие варианты Tension
  уже берёт) и нативное декодирование видео Theora (в Video.dll 2008 другая
  сборка libtheora), а также преобразования x87, размещение горячего кода и PGO
  из сборки 2009. Подробности — в [TECHDEBT-2008.md](TECHDEBT-2008.md).

Замеры на POCO X3 NFC (Snapdragon 732G, Adreno 618), 2400×1080, рендер 100 %,
полный HDR, ограничение 60 FPS (дисплей переключён на 60 Гц), неподвижная камера
10 с после входа в локацию, FPS. «До» — без сконвертированных текстур, AF ×16 и
кэша освещения; «после» — ETC2, AF ×4, кэш, два прогона:

| Локация | До | После |
| --- | --- | --- |
| Память (`Garden/trunkbright.xml`) | 26,3 | 40,8 и 46,8 |
| Остов (`Garden/trunk.xml`) | 24,0 | 34,3 и 34,2 |
| Озеро Ире (`Girl/ire.xml`) | 14,6 | 18,8 и 18,6 |
| Кузница Юны (`Girl/una.xml`) | 32,8 | 31,1 и 36,2 |
| Дом Яни (`Girl/yani.xml`) | 43,6 | 38,2 и 50,7 |

В первом прогоне «после» на Кузнице Юны и Доме Яни в окно замера попали
одиночные кадры по 100–130 мс; медиана кадра лучше в обоих прогонах
(27,6 и 27,4 мс против 30,4; 19,8 и 19,7 мс против 22,7). Вклад частей:
на Озере Ире почти весь прирост дал кэш освещения (15,4 FPS без него),
на Памяти и Остове — текстуры (31,0 и 27,1 FPS без копии).


## 0.2-dev — 2026-10-27

Development release of the native Android ARM64 port of **The Void (2009)** and **Tension (2008)**. Bring your own original game files.

## Changes

- Fixed the Body/Memory tutorial exit that could leave progression waiting after the screen closed. The original color refunds, inventory restoration and tutorial conditions are preserved. Updated the instructions in four languages and bundled six missing tutorial shaders.
- Improved color transfers, heart labels, Body-to-journal transitions, page navigation and the three-finger map gesture.
- Corrected shader state handling and SM3/HDR quality selection, audio listener parameters, voice/ambience routing and audio-worker scheduling. Added native fast paths for selected rendering and data-decompression operations.
- Updated developer location routes for both game versions, corrected legacy conversation/battle entry commands and removed routes with verified missing original dependencies.
- Improved native-library compression using independent 128 MiB XZ blocks and tuned LZMA literals. Compared with the first 0.2-dev package, the compressed libraries decreased from **147.1 MB to 138.3 MB (6.0%)** and the APK from **171.8 MB to 163.0 MB (5.1%)**. The unpacked library bytes are unchanged by repacking.
- Both APK builders now require an existing protected project signing key and stop if it is missing or unusable.

## Measured performance

Paired tests on a Snapdragon 8s Gen 3, with three loads per build and warm filesystem/shader caches:

| Location and route | Median loading time | CPU time during loading |
| --- | --- | --- |
| Map to Ire's Lake (`Girl/ire.xml`) | 11.22 → 10.34 s (**7.8% less**) | 11.94 → 10.82 s (**9.4% less**) |

A sustained FPS increase was not established in Ire (`Girl/ire.xml`), Yuna (`Girl/una.xml`) or Fog (`Park/foggyroots.xml`). The comparative CPU samples used the same 20 FPS limit and do not measure maximum FPS. The loading results are a small warm-cache sample.

## Download and update

- APK: **the-void-0.2-dev-20fc240f.apk**, **162,963,047 bytes**.
- Android version: **0.2-dev**, version code **3**.
- Signed with the same APK key as the previous release, for compatible updates.
- Original game resources must be supplied separately. Saves, settings and caches are stored in `userdata` next to the selected game copy.

Source licensing and third-party notices are included with the release.

Package validation passed: signature, ZIP integrity, 16 KB alignment, both native libraries, all **16,653 indexed asset records**, and independent-stream decoding through XZ Embedded. A corrupted-stream negative control was rejected.

This is a testing build. A complete playthrough and every language/device combination have not been exhaustively tested. First-launch unpack time with the larger blocks has not been remeasured on a phone. The reported persistent audio echo was not reproduced during validation.
